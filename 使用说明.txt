DownloadDock · 下载浮窗 v1.1
====================================

一个绿色免安装的小工具：桌面上有一个"↓ 下载"胶囊悬浮按钮（默认在屏幕
右上角），鼠标悬停会向下展开下载文件夹里最新的 5 个文件（按修改时间从
近到远，显示文件名 + 修改日期），按住任意一个文件拖出去，就能直接放进
Photoshop / Illustrator / 资源管理器等任何接受文件拖放的地方。

【运行要求】
Windows 10 / 11（64 位）。无需安装任何运行库，双击即用。

【快速开始】
1. 双击 DownloadDock.exe → 桌面出现悬浮按钮，任务栏托盘区出现图标。
2. 鼠标悬停悬浮按钮 → 展开文件列表。
3. 按住某一行 → 拖进 PS/AI 松手即可。
4. 按住悬浮按钮左键可把它拖到任意位置，位置会自动记住。

【操作一览】
  悬停悬浮按钮          展开 / 收起文件列表
  按住某一行拖出        把文件拖进 PS/AI/文件夹
  左键按住悬浮按钮      移动位置（自动记忆）
  双击某一行            用系统默认程序打开该文件
  右键某一行            打开文件 / 打开所在文件夹 / 复制完整路径
  右键悬浮按钮          设置 / 重置位置 / 打开下载文件夹 / 退出
  双击托盘图标          打开下载文件夹
  右键托盘图标          设置 / 重置位置 / 打开下载文件夹 / 退出

【设置】
- 下载文件夹：默认跟随系统设置。如果实际下载位置不是系统默认
  （比如改到了 D 盘），点"浏览..."选择实际文件夹，立即生效。
- 开机自动启动：勾选即写入当前用户的注册表启动项，取消勾选即关闭。
- 重置悬浮按钮位置：按钮找不到或跑到屏幕外时，用它一键找回。

【数据位置】
  设置与位置记忆：  %APPDATA%\DownloadDock\settings.txt
  日志：            %APPDATA%\DownloadDock\log.txt

【卸载】
托盘图标右键 → 退出（如有开机自启，先在设置里取消勾选），
然后删除 exe 文件和 %APPDATA%\DownloadDock 文件夹即可。

【提示】
- 正在下载中的临时文件（.crdownload / .part / .tmp 等）会自动过滤。
- 同一台电脑同时只会运行一个 DownloadDock。
- 文件夹内容变化时列表实时刷新，无需手动刷新。
